# My AI

> **My AI is an intelligent document-based AI assistant that lets users upload documents, chat with them, and control visibility through public or private access.**

An AI-powered knowledge platform where users can upload documents and interact with them through an AI chatbot. Documents can be marked **public** (visible to others in the same field) or **private** (visible only to the owner).

The goal of this project is to create a **smart collaborative knowledge system** powered by AI.

---

# Overview

My AI allows users to:

- Upload documents
- Chat with AI using document context
- Control document visibility (public/private)
- Share knowledge with others in the same field

The system combines **AI, document processing, and access control** to create a flexible knowledge assistant.

---

# Core Features

## AI Chatbot

Users can interact with an AI chatbot that understands uploaded documents.

### Capabilities

| Feature | Description |
|------|------|
| Document Q&A | Ask questions about uploaded documents |
| Context Awareness | AI reads document content before responding |
| Smart Responses | Answers are generated using document knowledge |
| Multi-user Support | Multiple users can upload and query documents |

---

## Document Visibility System

Every uploaded document can be controlled by the user.

### Two Visibility Modes

| Mode | Description |
|-----|-----|
| **Public** | Other users can view and query the document |
| **Private** | Only the document owner can access it |

This ensures users can **share knowledge when needed** while keeping sensitive data private.

---

## Knowledge Sharing

Public documents become part of a **shared knowledge base**.

Users in the same field can:

- discover documents
- learn from shared knowledge
- query documents using AI

This turns the platform into a **collaborative AI knowledge hub**.
